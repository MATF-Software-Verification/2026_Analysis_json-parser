## 2. Opis projekta

`json-parser` je DOM parser za JSON napisan u prenosivom ANSI C/C89. Analizirana verzija se nalazi u repozitorijumu seminarskog rada kao Git submodule.

## 3. Početno stanje

Na neizmenjenom analiziranom commit-u uspešno su izvršeni:

- generisanje build konfiguracije komandom `./configure`;
- prevođenje statičke i deljene biblioteke komandom `make`;
- strogo C89 prevođenje postojećeg C test programa;
- izvršavanje postojećih validnih, nevalidnih i extension test ulaza.

Početna provera nije prijavila neočekivano prihvatanje ili odbijanje test ulaza i završila se izlaznim kodom 0.
